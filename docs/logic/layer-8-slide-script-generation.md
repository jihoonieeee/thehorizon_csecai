# Layer 8 — Slide + Script Generation

## 1. Purpose

Generate the text on slides and the speaker script — LLM-driven but tightly constrained to pre-approved claims and pre-selected evidence. The LLM renders; it must not introduce claims, invent facts, or change claim meaning. Every number is re-checked against evidence.

Files: `lib/pipeline/slides/generateSlideContent.js`, `generateSpeakerNotes.js`, `qaSlideContent.js`, `qaSpeakerNotes.js`, `scriptGeneration/qaScript.js`.

## 2. Input

- **Input:** the slide plan from L7 (claim text, pre-selected `supporting_evidence` packets, caveats, visualization IDs, core_message).
- **Writes:** per-slide `headline`, `bullets[]` (with bullet_role + supporting_evidence_id), `evidence_callouts[]`, `citations[]`, `speaker_notes`, `speaker_notes_structured{}`.
- **Assumes from L7:** each analytical slide has a claim_id and resolved supporting evidence.

## 3. Sublayers / steps

### Slide content (`generateSlideContent.js`)
`slide_content` / `claim_first_slide` LLM (**Anthropic Opus claude-opus-4-8** → Gemini Pro). One call/slide. Two system prompts:
- **`CLAIM_FIRST_SYSTEM_PROMPT`** (analytical slides with a claim_id): the LLM's *only* job is to render the pre-approved claim — no new claims, no invented facts, no meaning change. Bullets carry `bullet_role` (finding/evidence/implication/caveat/action) + `supporting_evidence_id`. `evidence_callouts` must copy `evidence_id`/`title`/`publisher`/`url` exactly from the provided evidence (do NOT invent IDs).
- **`SYSTEM_PROMPT`** (structural slides): horizon-scan framing from category headlines; no pre-approved claim.

The LLM receives the approved claim text + pre-selected evidence packets + caveats + viz IDs + core_message. It does **not** receive the full dossier, other claims, raw source text, or cross-category context (except on cross-category slides).

Output: `{headline, bullets[], evidence_callouts[{evidence_id, title, key_fact, publisher, url, source_quote}], citations[]}`.

### Slide QA (`qaSlideContent.js`) — deterministic, per slide
**Blocking:** analytical slide without claim_id; `hallucinated_statistic` (a number in a bullet/headline not in any callout `key_fact`/packet `content.numbers` — years/durations/"Top 10" exempt); `citation_missing_url`; headline derives no key terms from claim_text (drift). On a hallucinated statistic → the bullet gets `[STATISTIC UNVERIFIED]` and the citation title is sanitized.
**Warnings:** bullet count outside 3–5; callout without source_quote; context-only evidence used for a claim-anchored assertion.

### Speaker notes (`generateSpeakerNotes.js`)
`speaker_notes` LLM (**Anthropic Opus** → Gemini Pro). One call/non-appendix slide. Receives slide number/type/headline/bullets/callouts (publisher + key_fact only, **not** raw text)/next-slide/intent. Fills `speaker_notes` + `speaker_notes_structured{main_point, evidence_significance, implication, transition}`. Rules: don't restate bullets verbatim, don't invent facts, no new claims, no hyperbole.

### Speaker-notes QA
- **Pass 1 (`qaSpeakerNotes.js`, deterministic):** no new numbers absent from callouts; no phantom publisher names. Runs on every slide.
- **Pass 2 (`qaScript.js`, `final_qa` LLM, Anthropic Sonnet → Gemini Pro):** **conditional** — only on slides Pass 1 flagged. Cross-provider (if notes generated by Anthropic, verify with Gemini, and vice versa). Checks grounding, phantom citations, new claims. Budget-capped (`SCRIPT_QA_BUDGET`, default 10); once exhausted, flagged slides pass with deterministic warnings only.

## 4. Fields produced

`headline, bullets[{text, bullet_role, supporting_evidence_id, linked_claim_id}], evidence_callouts[], citations[], speaker_notes, speaker_notes_structured{}`. QA adds `[STATISTIC UNVERIFIED]` markers, sanitized citations, and QA flags.

## 5. Assessment criteria

| Decision | Rule |
|---|---|
| Bullet validity | finding/evidence bullets need `supporting_evidence_id` |
| Number on slide | must appear verbatim in a cited callout/packet numbers |
| Citation validity | must contain a URL (analytical slides) |
| Headline | must share key terms with claim_text |
| Script claim | must trace to a callout fact; no new claims/numbers |

## 6. LLM calls

| Task | Model | Fallback | Trigger | Decides | Enforced after |
|---|---|---|---|---|---|
| `slide_content` / `claim_first_slide` | Anthropic Opus | Gemini Pro | each slide | headline/bullets/callouts | qaSlideContent (drops ungrounded numbers) |
| `speaker_notes` | Anthropic Opus | Gemini Pro | each non-appendix slide | spoken script | qaSpeakerNotes + conditional qaScript |
| `final_qa` | Anthropic Sonnet | Gemini Pro | Pass-1-flagged slides only | confirm phantom/new-claim/ungrounded-number | revise or mark `[UNVERIFIED]` |

Failure mode: LLM unavailable → deterministic content fallback (callouts from first rawfact items, evidence IDs preserved); notes default to "(No speaker notes)".

## 7. QA and anti-hallucination

- **Risk:** headline overstates the claim; bullet number not in evidence; script adds a new claim; citation to a non-supporting source.
- **Prevented by:** claim-first prompt (render only); number re-check against packet numbers (blocking); citation-URL requirement; speaker-notes Pass 1 + conditional cross-model Pass 2.
- **Missing:** headline "shares key terms" is a weak overstatement guard (a headline can be more assertive than its claim while sharing nouns); Pass 2 is budget-capped (flagged slides may pass with warnings only when budget is exhausted).

## 8. Downstream contract

L9 can assume: every slide's numbers trace to cited evidence, citations have URLs, and the script adds no new claims. It **cannot** assume the headline's *tone* matches the claim's confidence (only key-term overlap is checked), or that Pass-2 ran on every flagged slide (budget cap).

## 9. Known failure modes

- Headline can be more assertive than the claim while passing the key-term check.
- Budget-capped Pass 2 can leave a flagged script with deterministic warnings only.
- Structural (non-claim) slides synthesize from category headlines with looser grounding than claim-first slides.

## 10. Tests needed

- Number not in any callout → bullet dropped + `[STATISTIC UNVERIFIED]`; citation sanitized.
- Analytical slide without claim_id → blocked.
- Speaker notes introducing a new number/publisher → Pass-1 flag → Pass-2 (if budget).
- Headline sharing no key terms with claim → drift block.
