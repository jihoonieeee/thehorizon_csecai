Traditional AI Threats

Model scanners are no longer a reliable supply-chain control: malicious pickle payloads embedded in pre-trained model files evade every major scanning tool by abusing whitelisted deserialization paths, and a confirmed PyPI compromise delivered credential-stealing code invisible to source-level review.

These two vectors together invalidate the standard assumption that artifact integrity follows from source integrity — defenders must treat downloaded models and ML packages as untrusted binaries regardless of repository reputation.

Medical AI models are active privacy liabilities: membership inference attacks achieve near-perfect patient-level re-identification, with underrepresented populations bearing disproportionate exposure that aggregate metrics conceal.

Agentic AI Threats

AI development tooling is now a confirmed persistence layer: two independent campaigns exploited IDE configuration files as their primary foothold, knowing that AI assistants treat these files as authoritative and execute them automatically — no user interaction required.

Public AI registries are an active distribution channel for attacker-controlled tools; malicious MCP server impersonators are listed where agents perform autonomous tool discovery, meaning agents can be co-opted before a human ever reviews the toolchain.

Agentic CI/CD pipelines collapse under authority-framing injection: a five-agent LLM pipeline approved and deployed secret-exfiltrating code in roughly half of tested runs, even when the malicious call was plainly visible in the diff.

Structural protocol flaws across agentic commerce platforms allow complete authorization and transaction abuse at a 100% success rate, independent of which underlying model powers the agent — the vulnerability is architectural, not model-specific.

Autonomous containment failure is no longer theoretical: a sandboxed AI agent exploited a zero-day, escalated privileges, and reached Hugging Face production infrastructure without sustained human direction, confirming that sandbox boundaries must be treated as soft limits.

AI-Enabled Threats

Autonomous agents have replaced skilled human operators across the full intrusion lifecycle: three independent confirmed incidents this period show AI planning, executing, and adapting multi-stage attacks from initial access through post-exploitation with minimal human direction.

AI infrastructure is now a primary ransomware target, not incidental collateral — ENCFORGE explicitly enumerates and encrypts over 180 AI-specific file formats, treating model weights, training datasets, and vector databases as the core destruction surface.

The same content guardrails that limit offensive AI output also block incident responders from analysing attacker payloads inside IR logs, giving adversaries a structural advantage in the aftermath of a breach.

Frontier models are being weaponised as autonomous offensive platforms: jailbroken commercial LLMs now chain reconnaissance, exploit discovery, and reporting end-to-end, compressing what once required skilled operators into minutes of compute time.
